# UCI Online Retail II for Demand watch only

Status: accepted, 2026-11-17

The project needs a second real dataset from a different business to prove the data contract, but a second headline claim would dilute the proof and add work. UCI Online Retail II is real, public, about 1 million rows, one shop, product-day sales and prices, with no stock or empty-shelf flags. It is used only for Demand watch mode and the data contract. It never carries a core claim. The license is checked before use; if it fails, the fallback is M5 or Rossmann.

Consequences: the second dataset cannot prove the warning; it proves the front door and the watch mode; the Method page credits it; the license check is a task before loading it.
