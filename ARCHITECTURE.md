## Key Data Flows

_How data moves through the system for the most important operations._

### Authentication flow
```
User submits login form
→ Supabase Auth validates credentials
→ Sets JWT in httpOnly cookie via middleware
→ Middleware checks JWT on every protected route
→ Server Components read session via createServerClient()
```

### Payment flow
```
User clicks upgrade
→ POST /api/checkout creates Stripe session
→ User completes Stripe checkout
→ Stripe fires webhook to /api/webhooks/stripe
→ Webhook updates Plan in DB
→ User's UI reflects new plan
```
